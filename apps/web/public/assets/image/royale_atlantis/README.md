### Gameplay idea
- Use a 7×7 grid with 49 positions.
- Use a cluster-pay or ways-pay evaluation system suitable for a 7×7 board.
- Cascades remove winning groups and refill from above.
- Tidal Wild transforms only positions specified by the backend result.
- Atlantis Gate triggers a backend-authorized free-spin feature.
- Treasure Chest and Kraken Emblem trigger separate bonus states only when authorized by the server.
- Ocean Expansion may add rows during a feature, with the expanded board and result defined by the backend.

### Math and implementation notes
These files are visual symbol concepts cropped from the generated symbol-gallery artwork. They are high-resolution PNGs, but they are NOT individually re-illustrated transparent production sprites: the artwork retains its dark tile/background and ornamental frame. For production, redraw/export each icon as a clean transparent PNG or WebP, then define symbol weights, paytable, hit frequency, RTP and volatility in the backend game math. Never calculate real payouts or random outcomes in the browser.

### Suggested asset usage
- Keep the exact symbol IDs and filenames stable.
- Render each asset with `object-fit: contain`.
- Use consistent cell padding and aspect ratio.
- Do not use the poster image as a reel symbol.
