# Sky Rocket reference match

The Sky Rocket presentation was rebuilt from the user-supplied reference videos in the chat.

Implemented in the web app:
- dark radial/ray crash-game scene instead of the previous synthetic blue sky
- compact `FUN MODE` scene bar
- centered red multiplier presentation
- red server-driven jet sprite derived from the supplied reference video
- red flight ribbon/path
- crash impact keeps the jet visible with burning/fire/smoke presentation
- compact dark shell, history strip, and bet-card styling
- existing server-authoritative multiplier, betting, cash-out, reconnect and settlement wiring preserved

The file `apps/web/public/sky-rocket-reference-jet.png` is a transparent local presentation asset extracted from the user-supplied reference video for the game UI.
